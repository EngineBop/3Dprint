# Getting started

## Before the first print

1. Confirm the printer is assembled according to the supplied H2D setup guide and all shipping restraints have been removed.
2. Place the printer on a stable, suitable surface with adequate clearance and ventilation.
3. Complete the printer's on-screen initial setup and calibration prompts.
4. Install Bambu Studio on the workstation and add the **H2D** printer profile matching the installed nozzle configuration.
5. Check that the selected build plate and filament profiles match the physical setup.
6. Load compatible filament according to the printer and AMS 2 Pro instructions.
7. Run a small test print and record any deviations.

> Do not use setup or service steps written for the older CreatBot D600 Pro on the H2D.
