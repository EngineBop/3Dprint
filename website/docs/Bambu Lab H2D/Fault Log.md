## New incident checklist

- [ ] Record date, operator and job/model name
- [ ] Capture exact error message and photographs
- [ ] Note firmware, slicer, filament, nozzle, plate and AMS slot
- [ ] Document troubleshooting tests and results
- [ ] Record corrective action and parts used
- [ ] Verify the fix with a repeat print or appropriate test
- [ ] Link a dedicated Markdown fault report above
