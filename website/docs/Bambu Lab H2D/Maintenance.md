# Maintenance

## Routine operator checks

| When | Check | Action |
| --- | --- | --- |
| Before each print | Build plate condition | Check cleanliness, seating and damage |
| Before each print | Nozzles and print area | Look for residue, obstructions and loose material |
| Before each print | Filament and AMS | Confirm correct spool, routing and material condition |
| After each print | Print debris | Remove loose waste after safe cooldown |
| Periodically | Motion system and feed path | Inspect according to the current H2D maintenance guide |
| After an error | Affected component | Record symptoms before cleaning, adjustment or replacement |

> **Safety:** Let hot parts cool before contact. Isolate power before any service operation requiring it. Do not lubricate belts, rails or other components unless the H2D manufacturer's procedure specifically instructs it. Do not open electrical enclosures as routine operator maintenance.
